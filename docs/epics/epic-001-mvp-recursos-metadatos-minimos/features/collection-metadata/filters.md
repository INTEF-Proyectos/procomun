# Filtros avanzados de colecciones (#612)

El listado público combina el texto con idioma, palabras clave, áreas de conocimiento y etapa, programa o ámbito educativo de la colección. Reutiliza las opciones de recursos y los identificadores compartidos. Conserva el filtro en la URL al paginar, abrir una ficha y volver al listado. Limpiar devuelve la búsqueda a su estado inicial.

Las colecciones importadas pueden aprovechar los mismos filtros cuando el importador guarda sus metadatos (#615).
